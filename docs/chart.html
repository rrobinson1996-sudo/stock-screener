How to read it
  • X = price rising one box; O = falling one box. A new column starts only after a 3-box reversal, so small wiggles are ignored. Time isn't on the axis.
  • Bold column = that column triggered a signal: an X column above the previous X high is a BUY (double-top breakout); an O column below the previous O low is a SELL.
  • Numbers along the bottom = month each column started (1–9, A=Oct, B=Nov, C=Dec), with the year marked where it changes.
  • Lines: Now = latest close · Stop = 5×ATR stop · Target = measured-move objective.
  • Relative-strength chart: the stock divided by QQQ. Rising X's mean it's beating the index, the core leadership test.
  • Why the two charts use different box sizes: each box is sized to how much that line normally moves, so a signal means the same thing on a calm stock and a volatile one. The price box is 1× the stock's average daily range (ATR over 20 days) as a percent of price. The relative-strength line has no daily high or low, so its box is 1.5× its average daily move over 100 days. It usually moves less than the price, so its boxes are often smaller. Both are rounded to 0.25% and kept between 0.5% and 6%, and they're set fresh each day from the latest data.
  • The chart opens at the latest column; swipe left to see history.
